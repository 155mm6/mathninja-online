## 🔊 ЗВУКОВЫЕ ЭФФЕКТЫ

Все звуки генерируются **через Web Audio API** (без MP3/WAV файлов):

```javascript
Effects.playSound('correct')   // Правильный ответ
Effects.playSound('wrong')     // Неправильный ответ
Effects.playSound('levelUp')   // Конец уровня
```

**Как работает:**
1. Создаётся `AudioContext`
2. Генерируются волны синусоиды нужной частоты
3. Задаётся громкость и длительность
4. Воспроизводится через динамик

**Можно отключить** если звуки раздражают:
```javascript
// В game-new.js, в методе answerQuestion():
// Effects.playSound('correct');  // ← закомментировать
```

## 📊 АДАПТИВНОСТЬ ПРИМЕРЫ

### Старый CSS (неадаптивный):
```css
.title {
    font-size: 4rem;           /* Одинаковый для всех */
    margin-bottom: 2rem;       /* Фиксированный отступ */
    padding: 2rem;             /* Не меняется */
}
```

### Новый CSS (полностью адаптивный):
```css
.title {
    font-size: clamp(1.8rem, 8vw, 4rem);     /* Масштабируется! */
    margin-bottom: clamp(1rem, 5vw, 2rem);   /* Адаптивный отступ */
    padding: clamp(1rem, 5vw, 2rem);         /* Подстраивается */
}
```

**Как работает clamp():**
```
clamp(min, preferred, max)
   ↓       ↓           ↓
   ↓    МАСШТАБИРУЕТСЯ ↓
   └─────────────────────┘

На мобильном (320px):  min (1.8rem)
На планшете (768px):   preferred (8vw ≈ 60px)
На ПК (1920px):        max (4rem)
```

## 🎯 ФУНКЦИИ ИНТЕРАКТИВНОСТИ

```javascript
// Создание конфетти
Effects.createConfetti(x, y)
```

### Где вызывается

```javascript
// При правильном ответе
Effects.playSound('correct');

// При неправильном ответе
Effects.playSound('wrong');
Effects.createParticles(width/2, height/2, '❌', 4);

// При победе уровня
Effects.playSound('levelUp');
for (let i = 0; i < 10; i++) {
    Effects.createConfetti(
        Math.random() * window.innerWidth,
        Math.random() * window.innerHeight / 2
    );
}
```

### Размеры элементов (масштабируются):
```
Заголовок главного меню    → 1.8–4rem (8vw)
Заголовок уровня           → 1.2–2rem (4vw)
Вопрос                      → 1.5–2.5rem (5vw)

Кнопки                      → высота 45–100px (9–12vw)
```

### Расстояния (адаптивные):
```
Основной padding            → clamp(1rem, 2vw, 2rem)
Отступ между элементами    → clamp(0.5rem, 1.5vw, 1rem)
Gap в сетке                → clamp(0.5rem, 2vw, 2rem)
```

## ❓ ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

### Q: Как отключить звуки?
A: В методе `answerQuestion()` закомментируйте строки с `Effects.playSound()`

### Q: Как изменить сложность?
A: Отредактируйте `DIFFICULTY_CONFIG` в `game-new.js`

### Q: Как добавить новый остров?
A: Добавьте элемент в массив `ISLANDS` в `game-new.js`

### Q: Прогресс сохраняется?
A: Да, в `localStorage` браузера. Удалить: F12 → Application → Local Storage → Delete

### Q: Работает на старых браузерах?
A: Нужен Chrome 40+, Firefox 25+, Safari 9+, Edge 79+

Если что-то не работает:
