# 🏝️ Математический остров

Браузерная образовательная игра для детей 1–4 класса. Легкий, быстрозагружаемый MVP без внешних зависимостей.

## 🚀 Как запустить

1. **Локально в браузере:**
   - Откройте файл `index.html` в браузере (двойной клик или drag-and-drop)
   - Или запустите локальный сервер:
     ```bash
     # Python 3
     python -m http.server 8000
     
     # Python 2
     python -m SimpleHTTPServer 8000
     
     # Node.js (если установлен http-server)
     npx http-server
     ```
   - Откройте `http://localhost:8000` в браузере

2. **На мобильном:**
   - Разместите файлы на любом веб-сервере
   - Откройте URL с мобильного устройства
   - Игра адаптирована для всех размеров экранов

## 🎮 Как играть

### Основной цикл:
1. **Выбор класса** → выбирают сложность (1–4 класс)
2. **Карта островов** → выбирают остров
3. **Уровни** → решают 3 задания на каждом уровне
4. **Босс-испытание** → побеждают босса в финале острова
5. **Награды** → получают звёзды и очки
6. **Новые острова** → открывают следующие острова

### Система звёзд:
- **3 звезды** — все ответы правильные
- **2 звезды** — 66% правильных ответов
- **1 звезда** — 33% правильных ответов

### Открытие островов:
- **Остров 1** — открыт сразу (0 звёзд)
- **Остров 2** — нужно 6 звёзд
- **Остров 3** — нужно 12 звёзд
- **Остров 4** — нужно 18 звёзд
- **Остров 5** — нужно 24 звёзд
- **Финал** — нужно 30 звёзд

## 🔧 Архитектура генератора заданий

### Где находится:
Файл `game.js`, класс `QuestionGenerator` (строки ~35–120)

### Текущие типы заданий:

```javascript
generateAdditionQuestion()      // Сложение
generateSubtractionQuestion()   // Вычитание
generateMultiplicationQuestion()// Умножение
generateDivisionQuestion()      // Деление
generateTaskQuestion()          // Текстовые задачи
```

### Сложность по классам:

```javascript
DIFFICULTY_CONFIG = {
    1: { addition: { min: 1, max: 10 }, ... },
    2: { addition: { min: 10, max: 50 }, ... },
    3: { addition: { min: 50, max: 100 }, ... },
    4: { addition: { min: 100, max: 500 }, ... }
}
```

### Как добавить новый тип заданий:

**Шаг 1:** Добавить конфигурацию сложности в `DIFFICULTY_CONFIG`:
```javascript
DIFFICULTY_CONFIG = {
    1: { fractions: { num: 1, denom: 2 }, ... },
    2: { fractions: { num: 1, denom: 4 }, ... },
    // и т.д.
}
```

**Шаг 2:** Добавить метод генератора в класс `QuestionGenerator`:
```javascript
generateFractionsQuestion() {
    const config = this.difficulty.fractions;
    const numerator = this.random(1, config.num);
    const denominator = this.random(config.denom, 10);
    // ... логика генерации
    return {
        question: `${numerator}/${denominator} + ? = 1`,
        correct: denominator - numerator,
        distractors: this.generateDistractors(...)
    };
}
```

**Шаг 3:** Добавить в метод `generateQuestion()`:
```javascript
generateQuestion(type) {
    switch(type) {
        case 'fractions': return this.generateFractionsQuestion();
        // ... остальное
    }
}
```

**Шаг 4:** Создать новый остров в `ISLANDS`:
```javascript
{ id: 7, name: 'Остров Дробей', emoji: '🍰', type: 'fractions', requiredStars: 36 }
```

## 🏝️ Как добавить новый остров

**Шаг 1:** Добавить в массив `ISLANDS` в `game.js`:
```javascript
ISLANDS = [
    { id: 1, name: 'Остров Сложения', emoji: '➕', type: 'addition', requiredStars: 0 },
    // ... существующие
    { id: 7, name: 'Остров Процентов', emoji: '%️', type: 'percentages', requiredStars: 36 }
];
```

**Шаг 2:** Добавить тип заданий (см. раздел выше)

**Шаг 3:** Сохраняется автоматически — обновите страницу

**Параметры острова:**
- `id` — уникальный номер
- `name` — название (видно на карте)
- `emoji` — значок острова
- `type` — тип заданий (должен быть метод в `QuestionGenerator`)
- `requiredStars` — количество звёзд для открытия

## 💾 Сохранение прогресса

Прогресс автоматически сохраняется в `localStorage` браузера:
- Звёзды по уровням
- Общие очки и опыт
- История решённых заданий

Данные хранятся локально и не отправляются на сервер.

## 🐛 Известные ограничения MVP

5. Нет статистики по типам ошибок
